BAB II — LANDASAN TEORI

Objek Penelitian, Sumber Data & Scraping

🏛️

Program MBG

Program prioritas nasional dikelola Badan Gizi Nasional (BGN), berjalan sejak 6 Jan 2025 di 38 provinsi untuk gizi anak & kelompok sasaran.

🌐

Platform X

Platform mikroblog (280 karakter) real-time, terbuka, dengan fitur retweet & hashtag. Sumber data valid untuk riset opini & sentimen publik.

🛠️

Tweet Harvest

Tool data scraping berbasis browser automation (Playwright) untuk mengekstraksi cuitan secara otomatis berdasarkan kata kunci & rentang tanggal.

BAB II — LANDASAN TEORI

Pemrosesan Teks & Analisis Sentimen

🧠 Natural Language Processing

Cabang kecerdasan buatan (AI) yang memungkinkan komputer memahami, mengolah, dan mengekstraksi makna dari bahasa manusia alami (fokus NLU).

🎯 Analisis Sentimen

Metode pengelompokan opini ke polaritas Positif, Netral, atau Negatif pada tingkat kalimat/cuitan.

🧹 Text Preprocessing

Tahap membersihkan noise teks mentah media sosial: Case Folding, Cleaning (hapus URL/mention/emoji), Normalisasi slang/typo, & Dedup.

BAB II — LANDASAN TEORI

IndoBERTweet & Fine-Tuning Model

🤖

Model IndoBERTweet

Model pre-trained BERT pertama yang dirancang khusus untuk teks Twitter berbahasa Indonesia.

  • ✓ Dilatih pada 409 juta token tweet informal.
  • ✓ Sangat adaptif terhadap kata gaul, singkatan, & slang X.
⚙️

Proses Fine-Tuning

Proses melatih ulang model pre-trained agar mampu menyelesaikan tugas klasifikasi spesifik.

  • ✓ Menyesuaikan bobot (weights) pada dataset cuitan MBG.
  • ✓ Mengklasifikasikan teks ke dalam 3 kelas sentimen secara akurat.
BAB II — LANDASAN TEORI

Evaluasi Performa Model

Accuracy

Rasio prediksi benar dari seluruh data uji.

Precision

Tingkat ketepatan antara data terprediksi positif dengan data aktual.

Recall

Tingkat keberhasilan model menemukan kembali data kelas aktual.

F1-Score

Rata-rata harmonik presisi & recall (metrik utama evaluasi data unbalanced/macro).

Diukur menggunakan Confusion Matrix 3x3 untuk menganalisis detail prediksi benar dan kesalahan antar kelas.
